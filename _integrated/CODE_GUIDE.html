1. 전체 개요

1.1 시나리오 파이프라인

프롬프트("마리오 잡아와") └→ 사물 좌표 조회 └→ A* 경로계획 (출발 → 사물 앞 staging) └→ holonomic trot 보행으로 추종 └→ [도로] 비전으로 신호등 초록 인지 → 횡단보도 통과 └→ 사물 앞 정밀 접근 (APPROACH) └→ top-down 팔 IK 하강 → 스냅 + weld 파지 └→ 들어올림 (LIFT) └→ 복귀 A* + 횡단보도 재통과 └→ 최종 위치(0,-19)에서 weld 해제 (내려놓기)

1.2 파일 구성

파일역할
main_task.py통합 컨트롤러 (보행·IK·비전·FSM·CLI 전부)
scene_task.xml친구 맵 scene_map.xml include + 사물 6개 + 파지 weld
_cam_view.py로봇 카메라 3패널 별창 (matplotlib, 별도 프로세스)
assets/<이름>/사물 메쉬(model.obj) + 텍스처(texture.png)

원본 _taekyeong/·_jaemin/ 파일은 수정하지 않고 include/재사용한다.

<mujoco>
  <include file="../_taekyeong/scene_map.xml"/>        <!-- 맵 그대로 -->
  <asset>  <!-- 키별 prefix로 이름 충돌 방지 -->
    <texture name="mario_tex" file="assets/mario/texture.png"/>                    <!-- 모델디렉토리 상대 -->
    <material name="mario_mat" texture="mario_tex"/>
    <mesh name="mario_mesh" file="../../../_integrated/assets/mario/model.obj" scale="..."/>  <!-- meshdir 상대 -->
  </asset>
  <worldbody>
    <body name="obj_mario" pos="-22.7 22.05 0.20">
      <freejoint name="mario_free"/>
      <geom type="mesh" mesh="mario_mesh" material="mario_mat" mass="0.2" condim="6"/>
    </body>
  </worldbody>
  <equality>
    <weld name="grab_mario" body1="arm_link_fngr" body2="obj_mario" active="false" solref="0.02 1"/>
  </equality>
</mujoco>
경로 핵심 — 맵을 include하면 meshdir이 spot assets로 잡힘.
· 텍스처 file= 는 모델 디렉토리(_integrated) 상대 → assets/mario/texture.png
· 메쉬 file= 는 meshdir 상대 → ../../../_integrated/assets/mario/model.obj
둘 다 상대경로라 다른 PC에서도 동작.

4. main_task.py — 섹션별 설명

4.0 모듈 로드 & 런타임 설정

  • scene_task.xml로 model/data 로드. IK 전용 사본 ik_model/ik_data(실제 시뮬과 분리).
  • traffic.GREEN_DURATION=16, TRAFFIC_CYCLE=24 — 초록불 연장(도로 완전 횡단 시간 확보).
  • pathfinding._OBSTACLES += [초록 플랫폼 3개] → A*가 0.2 m 턱을 피해 가장자리로 접근.

4.1 유틸리티

get_act / jnt_qadr / jnt_dadr / jnt_range / body_id / eq_id(이름→인덱스), quat_to_rpy, clamp, wrap_angle.

4.2 사물 레지스트리

  • Obj 데이터클래스: key, body, free, weld, start(위치), stop(staging) + 런타임 인덱스.
  • stop = 사물에서 ~1.6 m 떨어진 staging point(플랫폼 인플레이션 밖). 최종 0.62 m 접근은 APPROACH 담당.
  • reset_objects(): 키프레임 패딩으로 0이 된 사물 qpos를 받침 위로 재배치.
  • parse_prompt(text): 프롬프트에서 사물 키 추출.

4.3 다리 기구학 + holonomic 보행

  • fk/leg_ik: 한 다리 2관절(hy, kn) 정/역기구학.
  • foot_traj(phase, vx, vyaw, hip_x, hip_y) — 정지 동안 발이 몸체에 대해 -(V + ω×r) 만큼 쓸려 미끄럼 없이 추진/회전:
    Sx = (vx - vyaw·hip_y)/FREQ (앞뒤), Sy = (vyaw·hip_x)/FREQ (좌우 ← 회전 핵심).
  • apply_legs: 측면 발 오프셋 dy → hx = asin(dy/L) 로 변환.
개선 — 원래 회전이 stride 차분에만 의존해 느렸음(6°/s). holonomic 측면 발배치(hx) 추가로 ~20°/s 로 강화.

4.4 팔 IK + 그래스핑

  • ARM_SEED(준비)/ARM_STOW(접음), step_arm_toward(rate-limit로 부드럽게).
  • solve_arm_ik(target, seed, approach_axis) — Damped Least Squares. approach_axis 주면 그리퍼 접근축을 그 방향으로 정렬 → top-down 파지(GRASP_AXIS=(0,0,-1)). 위치(3)+방향(3) 6-DoF.

4.5 weld 파지 / 해제

  • attach(obj): 상대 자세 계산 후 weld 활성화. 그리퍼가 사물 0.16 m 이내일 때만 부착(폭발 방지).
  • detach(obj): weld 비활성(내려놓기).
개선 — 작은 물건 마찰 파지가 불안정해 튕겨나감. → 하강 중 사물을 그리퍼 끝으로 스냅 + soft weld(solref="0.02 1")로 전환 → 6개 전부 안정.

4.6 비전 — 신호등 인지 (Vision)

  1. 로봇에서 가까운 신호등(남 TL_BOTTOM/북 TL_TOP) 선택.
  2. 그 신호등을 보는 오프스크린 카메라로 렌더.
  3. 초록 픽셀 수 vs 빨강 픽셀 수 비교 → 초록 우세하면 green (운반 사물이 가려도 강건).
성능 — 비전 렌더는 무거워서 0.1초마다(20스텝)만 호출하고 결과 캐시 → 횡단보도에서도 배속 유지.

4.7 횡단보도 게이트 (CrosswalkGate)

양방향(남↔북) 도로 진입 전 정지. idle → waiting → crossing. 빨강을 본 뒤 초록(신선한 초록)이어야 출발 → 횡단 중 빨강 전환으로 차에 치이는 것 방지.

4.8 경로계획 & 추종

  • plan(start, goal): astar + smooth_path. 도로 횡단 시 중앙선(x=0) 직진 경유점 (0,8.8),(0,1.0) 강제 삽입.
  • PathFollower: pure-pursuit. 헤딩 오차 작으면(<0.05 rad) 회전 0 → 직진 흔들림 억제.

4.9 FSM (main 루프)

상태하는 일
GO_TO_OBJECTstaging까지 A* 추종 + 횡단보도 게이트, 팔 접음
APPROACH사물 정면 0.62 m 정밀 접근(최소 0.5 m/s로 저속 게이트 회피)
PRE_GRASP사물 위 18 cm top-down IK
DESCEND하강하며 0.16 m 근접 시 스냅+weld
CLOSE그리퍼 닫는 모션(시각용)
LIFT사물 들어올림
RETURN(0,-19) 복귀 A* + 횡단보도 재통과, 운반 자세 유지
PLACE_DOWN → RELEASE → DONE팔 하강 → weld 해제(내려놓기) → 종료

4.10 녹화 / 카메라 / 배속 / CLI

--speed=N
sleep을 dt/N로 축소. 고배속엔 렌더 빈도도 감소.
--cam
별도 프로세스로 body/arm/신호등 3패널 표시.
--record
추적+비전 합성 프레임을 frames/에 PNG 저장.
--headless
뷰어 없이 최대 속도 + 결과 출력.

6. 실행법

cd _integrated
python main_task.py                          # 대화형("공룡 잡아와")
python main_task.py --obj=mario              # 직접 지정 (뷰어)
python main_task.py --obj=mario --speed=5    # 5배속
python main_task.py --obj=mario --cam        # 카메라 별창 함께
python main_task.py --obj=mario --speed=5 --cam   # 추천
python main_task.py --headless --obj=mario   # 결과만 빠르게
python main_task.py --record  --obj=mario    # frames/ 에 녹화

물건 키: mario, yoshi, android, dino, elephant, dog
